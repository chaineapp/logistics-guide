The Checkpoint Library

Checkpoints are the automated touchpoints Chain's tracking agent runs across a load's journey — each one watches for a moment and reaches out to the driver at exactly the right time. This is a catalog of the checkpoints teams rely on across the shipment lifecycle, to spark ideas for your own.

How to design your own

Every checkpoint is built from three simple parts. Mix them to fit your lanes and customers.

When it fires

Relative to a milestone — a set time before or after the pickup or delivery appointment, the live ETA, or an arrival/departure.

On a change — the moment a load is booked, or when it starts moving.

On a geofence — as the truck enters or leaves a stop.

When it should apply

Add conditions so a checkpoint only fires when it's useful — e.g. only if the driver's phone is on file, only while the load is in transit, or only on multi-day hauls. Conditions also let a checkpoint auto-stop once its job is done (tracking accepted, POD received).

Patterns worth copying

Appointment vs ETA twins — run the same delivery check off both the booked appointment and the live ETA to cover loads that drift.

Escalation ladders — repeat a nudge at widening intervals (reminder → 2nd → final) until the driver complies.
