# Autopilot Checkpoint Library

Checkpoints are the automated touchpoints Chain's tracking agent runs across a load's journey — each one watches for a moment on a shipment and reaches out to the driver at exactly the right time. Browse the library below by lifecycle stage, search it, and **copy any checkpoint as a starter template** for your own.
